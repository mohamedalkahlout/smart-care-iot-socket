## 🎯 هوية المشروع ورسالته الجوهرية (Vision & Mission)

مقبس ذكي تحديثي (Retrofit) مخصص للأجهزة الكهربائية والحرارية (سخانات، مكيفات، ثلاجات) في بيئات **رعاية كبار السن والأطفال**، يعمل بمبدأ **«الأمان أولاً (Safety-First Architecture)»**. يتميز النظام بـ:
1. **حارس صلب معزول (`Safety Guard`)** مكتوب بلغة ANSI C ومستقل تماماً عن السحابة لاتخاذ القرارات الحرجة ومنع الحرائق وتلف الضاغط.
2. **نموذج تكيفي خفيف على الحافة (`NLMS Edge Model`)** يستهلك أقل من 24 بايت من الذاكرة العشوائية لتقليل إجهاد المرحلات الكهربائية وتوفير الطاقة.
3. **استقلالية تامة عند انقطاع الشبكة**، مع توفير واجهة ويب متجاوبة وثنائية اللغة لمقدم الرعاية ومساعد أوامر مقيد بمخطط صارم يرفض التعليمات الخطرة.

## 🔬 الشفافية العلمية والنتائج التجريبية (Empirical Results & Limits)

> 📑 **التقرير الأكاديمي والتحليلي الكامل:** راجع وثيقة [docs/EVALUATION.md](docs/EVALUATION.md) للاطلاع على البيانات التفصيلية.

### 1. تفوق التحكم التنبؤي وإطالة عمر المرحل (RQ1):
أثبتت نتائج 30 تشغيلاً مستقلاً (7200 دقيقة لكل تشغيل) تفوق خوارزمية التحكم التكيفي:
- **خفض دورات تبديل المرحل (Relay Chatter Reduction):** انخفضت الدورات بنسبة **68.4%** (من 72.9 إلى 23.0 دورة لكل 5 أيام)، مما يضاعف العمر الافتراضي للمرحل الميكانيكي وضاغط التبريد بأكثر من ثلاثة أضعاف.
- **جودة الراحة الحرارية:** انخفاض وقت الخروج عن نطاق الراحة بمقدار **253.4 دقيقة (-11.5%)** مقارنة بالتحكم التقليدي بالعتبة.

### 2. حدود كشف الشذوذ الحالية ومصارحة البحث (RQ2):
- **في بيئة المحاكاة الاصطناعية المثالية:** حقق كشف فتح الباب دقة واستدعاءً بنسبة **100%**.
- **في اختبار الإجهاد الواقعي (Real-World Stress Test):**
  - عند إدخال ضجيج في قراءات المستشعر ($\sigma = 0.08$°م)، ارتفع **معدل الإنذارات الكاذبة إلى 16.0%**.
  - في حالات التسريب الطفيف من إطار الباب (Gasket Leak)، هبط **معدل الاستدعاء إلى 28.0% فقط** بسبب انخفاض الميل الحراري عن العتبة الصلبة.
  - **الاستنتاج الهندسي:** العتبات الحدية الثابتة غير كافية بمفردها في الميدان الحقيقي، وتتطلب في النظم الصناعية دمج مرشحات كالمان التكيفية (Kalman Filtering) ونوافذ تكاملية متعددة المقاييس.

## 🔌 تعيين دبابيس العتاد (ESP32-DevKitC-v4 Pinout Mapping)

| الدبوس | الوظيفة | الاتجاه | الخصائص الكهربائية |
|---|---|---|---|
| **GPIO 2** | إشارة المرحل (`PIN_RELAY`) | خرج (Output) | معزول بمزدوج ضوئي (Optocoupler)، افتراضي مطفأ (Failsafe OFF) |
| **GPIO 4** | زر الطوارئ المحلي (`PIN_BUTTON`) | دخل (Input) | مفتاح إلى الأرضي مع مقاومة رفع داخلية وإخماد تذبذب (50ms Debounce) |
| **GPIO 15** | حساس الحرارة والرطوبة (`PIN_DHT`) | دخل (Input) | خط بيانات أحادي DHT22 مع مقاومة سحب خارجية 4.7kΩ |
| **GPIO 18** | مؤشر التنبيه (`PIN_ALERT_LED`) | خرج (Output) | وميض تحذيري عند الأوامر الخارجية أو تدخل حارس الأمان |
| **GPIO 19** | مؤشر الحالة والشبكة (`PIN_STATUS_LED`)| خرج (Output) | نبضات الحالة واستقرار الاتصال بالشبكة |

## 📁 الهيكل الشجري للمشروع (Clean Architecture Layout)

```
.
├── firmware/              # كود البرمجيات المضمنة لشريحة ESP32 (PlatformIO / C++)
│   ├── include/           # ترويسات C: safety_guard.h, control_logic.h, thermal_model.h
│   ├── src/               # main.cpp, safety_guard.c, control_logic.c
│   └── platformio.ini     # إعدادات البناء والتصريف لشريحة esp32dev
├── simulator/             # محاكي الغرفة الحراري الفيزيائي (Python 1R-1C)
├── ml/                    # نماذج التعلم التكيفي على الحافة (NLMS) وتحليل الشذوذ

├── app/                   # لوحة التحكم المتجاوبة وثنائية اللغة لمقدم الرعاية (WCAG AA)
├── docs/                  # التوثيق الشامل: المعمارية، الأمان، التقييم، ونموذج التهديدات

│   └── academic_poc/      # ملفات محاكي Wokwi والتقرير والعرض التقديمي الأصلي
├── scripts/               # سكربتات الصيانة والنظافة التلقائية للمستودع
├── tests/                 # اختبارات الوحدة والمطابقة الصارمة (19 اختبار مؤتمت)
├── run_tests.py           # مشغل الاختبارات الموحد بضغطة واحدة
├── LICENSE                # رخصة أباتشي 2.0 الرسمية (Apache License 2.0)
├── CONTRIBUTING.md        # القواعد الصارمة للمساهمة والأمان

```

## ⚡ البدء السريع في 3 خطوات (Quickstart)

### 1. تشغيل الفحص والاختبارات الشاملة:
```bash
python run_tests.py
```

### 2. تشغيل محاكي الغرفة الحراري والتحقق من التليمترية:
```bash
python simulator/thermal_room_simulator.py
```

### 3. فتح لوحة تحكم مقدم الرعاية وتشغيل خادم الواجهات:
```bash
# تشغيل بوابة الأوامر والسجلات المهيكلة
python cloud/api_server.py

# ثم افتح الملف app/index.html في أي متصفح
```
