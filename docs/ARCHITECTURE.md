# المعمارية الشاملة للنظام (ARCHITECTURE.md)

مشروع «المقبس الذكي» مبني وفق معمارية متعددة الطبقات تفصل تمامًا بين **التحكم والقرارات الفيزيائية المحلية** و**خدمات السحابة والمزامنة**.

```
┌────────────────────────────────────────────────────────┐
│                   ESP32 Hardware Core                  │
│                                                        │
│  [DHT22] ──► [Sensor Filter] ──► [Control Logic]      │
│                                         │              │
│  [GPIO4 Button] ──(Priority Override)───┤              │
│                                         ▼              │
│                                  [Safety Guard]        │
│                                         │              │
│                                         ▼              │
│                                  [Relay Actuator]      │
└───────────────────────────┬────────────────────────────┘
                            │ (Local Offline Autonomy)
                            ▼ (TLS / HTTPS Batching)
┌────────────────────────────────────────────────────────┐
│                     Cloud & Services                   │
│                                                        │
│   • Firebase Realtime Database (Schema Enforced)       │
│   • Append-Only Telemetry Logger                       │
│   • Caregiver Roles & Invitation Service               │
│   • Push Notifications (Telegram / Webhook)            │
└───────────────────────────┬────────────────────────────┘
                            │ (WCAG AA Web API)
                            ▼
┌────────────────────────────────────────────────────────┐
│               Caregiver Web Dashboard (PWA)            │
│   • Emergency 1-Click Immediate Off                    │
│   • Decision Source Transparency                       │
│   • Arabic / English Bilingual Interface               │
└────────────────────────────────────────────────────────┘
```

## ما تم تنفيذه مقابل ما هو مخطط (Audit of Implementation):

| الميزة | الحالة في المشروع المطور | الوصف |
|---|---|---|
| حارس الأمان الصلب (`safety_guard`) | **منفذ بالكامل** | وحدة C++ وPython تفرض 8 قواعد صارمة وتمنع التشغيل الخطير. |
| منطق الأجهزة مع Hysteresis | **منفذ بالكامل** | يدعم `cooling`, `heating`, `compressor`, `generic`. |
| استمرارية العمل دون إنترنت (Offline) | **منفذ بالكامل** | الجهاز مستقل ويثبت إعداداته في ذاكرة NVS ولا يعتمد على الشبكة. |
| أولوية الزر الفيزيائي | **منفذ بالكامل** | مقاطعة على GPIO4 بفلترة Debounce تلغي أي أمر بعيد. |
| المحاكي وتوليد البيانات | **منفذ بالكامل** | محاكي غرف 1R-1C ولّد 60 يومًا من البيانات الاصطناعية. |
| الذكاء الخفيف على الحافة | **منفذ بالكامل** | خوارزمية NLMS بقدرة تنبؤ بالحرارة واكتشاف شذوذ الثلاجة. |
| لوحة التحكم لمقدم الرعاية | **منفذ بالكامل** | واجهة ويب متجاوبة وثنائية اللغة مع زر إطفاء طوارئ. |
| قياس التيار في المحاكاة | **مخطط للعتاد** | يتطلب في العتاد الفعلي إضافة شريحة PZEM-004T أو HLW8012. |
