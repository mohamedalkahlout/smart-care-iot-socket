# دليل المحاكاة والتشغيل (SIMULATION_GUIDE.md)

يوفر هذا المستند خطوات تشغيل واختبار نظام المقبس الذكي بالكامل في بيئة المحاكاة خلال دقائق معدودة.

---

## 1. تشغيل الاختبارات الآلية الموحدة (Unit Tests)

قم بتشغيل الأمر التالي للتحقق من سلامة كافة الوحدات:

```bash
python run_tests.py
```

يقوم هذا السكربت بفحص:
- حارس الأمان (`test_safety_guard.py`): قطع الحرارة، صلاحية الحساس، حماية الضاغط، مؤقت السخان.
- منطق التحكم (`test_control_logic.py`): الـ Hysteresis، أولوية الزر الفيزيائي، استمرارية العمل دون إنترنت.

---

## 2. توليد بيانات التليمترية الاصطناعية (60 يومًا)

لتوليد سجل سلاسل زمنية واقعي وموثوق لأغراض التدريب والتقييم:

```bash
python simulator/thermal_room_simulator.py
```

- **الناتج:** ملف `simulator/telemetry_60days.csv` يحتوي على 8640 سجلاً دوريًا مع أعطال محقونة (فقد حساس، باب ثلاجة مفتوح، انقطاع شبكة، انقطاع كهرباء).

---

## 3. تقييم نماذج الذكاء الاصطناعي وخوارزميات التحكم

### تقييم النموذج الحراري الخفيف (NLMS):
```bash
python ml/thermal_model.py
```
يقوم بحساب MAE و RMSE ومقارنتها بخط الأساس لتقدير حرارة الغرفة بعد 15–30 دقيقة.

### تقييم مقارنة المتحكمات (30 تشغيل):
```bash
python ml/adaptive_controller.py
```
يقوم بتشغيل 30 محاكاة مستقلة ويحسب عدد دورات تبديل الريليه والراحة الحرارية واستهلاك الطاقة.

### تقييم شذوذ الثلاجة:
```bash
python ml/fridge_monitor.py
```

---

## 4. تشغيل لوحة التحكم التجريبية لمقدم الرعاية

افتح الملف `app/index.html` في أي متصفح حديث (Chrome / Firefox / Edge).  
يمكنك اختبار:
- زر الإطفاء الفوري للطوارئ.
- تبديل اللغة (عربي / إنجليزي).
- تعديل حدود الراحة وحفظها.
- استعراض أسباب القرارات وقواعد حارس الأمان.
