## 📌 نبذة عن النموذج الأولي (Historical Context)
انطلق المشروع كبحث وتطبيق أكاديمي لنظام تحكم بيئي للمقابس الذكية باستخدام محاكي Wokwi وشريحة ESP32 مع قاعدة بيانات Firebase Realtime Database. كان الهدف الأساسي للنموذج الأولي إثبات الجدوى (Proof of Concept - PoC) للتحكم عن بعد وقراءة درجات الحرارة والرطوبة عبر بروتوكول HTTP والواجهات البسيطة.

### محتويات هذا المجلد:
1. **`wokwi_simulation/`:** ملفات المحاكاة الأصلية (`diagram.json`, `sketch.ino`, `index.html`, `wokwi-project.txt`) التي استخدمت في منصة Wokwi.
2. **`documents/`:** التقرير الأكاديمي النهائي للمشروع (`Smart_IoT_Socket_Project_Report_M_AlKahlout.pdf`) والعرض التقديمي (`Presentation_SmartSocket_EN.pptx`).
3. **`prototypes/`:** النسخ والمسودات البرمجية المبكرة، ونماذج قواعد البيانات المصدرة بصيغة JSON (`.json`)، وملفات الأرشيف التاريخية.

## ⚖️ المقارنة المعمارية: النموذج الأولي مقابل النظام المطور

يوضح الجدول التالي النقلة النوعية بين النموذج الأولي الأكاديمي المرجعي والمعمارية الصناعية المطورة:

| وجه المقارنة | النموذج الأولي الأكاديمي (هذا المجلد) | النظام المطور الحالي (`firmware/`, `ml/`, `cloud/`) |
|---|---|---|
| **فلسفة المعمارية** | معمارية عامة قائمة على السحابة (Cloud-Reliant) | معمارية «الأمان أولاً» على الحافة (Safety-First Retrofit Edge-AI) |
| **طبقة حماية العتاد** | تحكم برمجي مباشر دون عوازل حماية صلبة | **حارس أمان صلب معزول (`Safety Guard`)** بلغة ANSI C يمتلك أولوية الإلغاء المطلقة |
| **خوارزمية التحكم** | عتبة بسيطة (Bang-Bang On/Off) تسبب تآكلاً سريعاً للمرحل | **تحكم تكيفي ذكي (NLMS + Hysteresis)** يقلل دورات التبديل بنسبة **68.4%** |
| **الاعتمادية عند انقطاع الشبكة** | يتوقف النظام أو يفقد التحكم الخارجي | تشغيل محلي كامل وذاتي ومستمر دون الحاجة إلى السحابة للقرارات الحرجة |
| **حماية الضاغط (Refrigerators)** | لا توجد حماية ضد دورات التشغيل القصيرة | حماية مدمجة ضد الدوران السريع (Anti-Short-Cycle Protection) بفترة انتظار 180 ثانية |
| **أمان قواطع السخانات** | مراقبة اعتيادية فقط | قاطع إجباري عند 35°م وسقف زمني للتشغيل المستمر (30 دقيقة كحد أقصى) |
| **مساعد الأوامر** | نصوص ثابتة غير مقيدة | مساعد لغوي مقيد بمخطط صارم (`JSON Schema`) يرفض الأوامر الخطرة تلقائياً |
