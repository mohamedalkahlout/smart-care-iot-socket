# دستور وقواعد العمل البرمجية (CLAUDE.md)
## SmartCare Multi-Socket IoT Safety Hub

### المبادئ الهندسية الصارمة:
1. **الأمان أولاً (Safety-First):** لا يجوز لأي أمر سحابي أو محلي تشغيل أي قناة دون المرور بحارس الأمان في ANSI C (`safety_guard.c`).
2. **استقلالية الحافة (Offline-First):** النظام يعمل محلياً بكفاءة 100% دون اتصال بالإنترنت، ويخزن إعداداته في ذاكرة NVS.
3. **انعدام الحجز الديناميكي للذاكرة (Zero Dynamic Allocation):** كود C لا يستخدم `malloc` أو `free` لتفادي تجزئة الذاكرة وتجميد النظام.
4. **تطابق الاختبارات 1:1:** أي تعديل في قواعد C يجب أن يتبعه تعديل متطابق في نسخة Python مع تشغيل `run_tests.py` واجتياز كافة الاختبارات.
5. **منع الأكواد المكررة والمجزأة:** المشروع مستودع موحد وشامل، ولا يجوز إعادة تجزئته إلى مجلدات فرعية متكررة.
