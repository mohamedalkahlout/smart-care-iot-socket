## 📖 نظرة عامة ورؤية المشروع (Project Overview)

يهدف مشروع **SmartCare Multi-Socket Hub** إلى حل مشكلة خطيرة في إدارة الطاقة المنزلية للأجهزة الحساسة والحرارية (سخانات، مكيفات، مضخات مياه، أجهزة ترفيهية):
1. **معالجة نقاط الضعف التقليدية:** إزالة الاعتمادية الخطيرة على الاتصال السحابي الدائم؛ حيث يستمر الجهاز بالعمل الآمن المستقل حتى في حال انقطاع الإنترنت التام.
2. **حارس أمان فيزيائي صلب (`safety_guard.c`):** طبقة فحص إلزامية معزولة بلغة ANSI C تمنع تجاوز الحدود الحرارية، واحتراق ملفات المواتير، والقفل الميكانيكي لضواغط التبريد.
3. **أربعة مقابس نشطة ومحمية بالكامل في منظومة واحدة:**
   - **قناة 1 (المقبس الحراري):** تحكم ذكي بالسخانات والمبردات مع حماية من تجاوز الحرارة وسقف تشغيل مستمر (120 دقيقة).
   - **قناة 2 (مضخة المياه):** حماية من التشغيل المفرط (سقف 20 دقيقة لمنع احتراق الموتور وفيضان الخزان) مع فترة تبريد إجبارية (5 دقائق).
   - **قناة 3 (التلفاز ومحطة العمل):** مؤقت إطفاء ذكي للقضاء على طاقة الاستعداد المهدورة (Vampire Drain).
   - **قناة 4 (التكييف والضاغط الحثي):** تأخير زمني إلزامي (180 ثانية) لحماية الضاغط من التبديل السريع (Anti-Short-Cycling).
4. **زر إيقاف الطوارئ الشامل (Master Emergency All-Off):** زر فيزيائي وبرمجي يقطع جميع القنوات الأربعة فوراً في أقل من 50 ملي ثانية.

## ⚡ البدء السريع (Quickstart)

### 1. تشغيل كافة الاختبارات الآلية:
```bash
python run_tests.py
```

### 2. بناء الـ Firmware عبر PlatformIO:
```bash
cd firmware
pio run
```

### 3. تجربة المحاكي الفيزيائي للأحمال المتعددة:
```bash
python simulator/multi_socket_simulator.py
```

### 4. فتح لوحة التحكم:
افتح الملف `app/index.html` في متصفحك مباشرة؛ ستتصل اللوحة تلقائياً بقاعدة بيانات المشروع الموحد وتتيح لك التحكم بجميع المقابس الأربعة وزر الطوارئ.

## 🔌 جدول التوصيل الفيزيائي (Hardware Pinout)

| القناة / المكون | الدبوس (GPIO) | نوع الحمل | وظيفة الحماية الأساسية |
|---|---|---|---|
| **Relay 1** | **GPIO 2** | سخان / مبرد | قطع حراري مطلق عند 45°م وسقف ساعتان |
| **Relay 2** | **GPIO 18** | مضخة المياه (ماتور) | سقف تشغيل 20 دقيقة وتبريد إلزامي 5 دقائق |
| **Relay 3** | **GPIO 19** | التلفاز والأجهزة الترفيهية | إطفاء تلقائي بعد 4 ساعات لمنع هدر الاستعداد |
| **Relay 4** | **GPIO 21** | التكييف (ضاغط حثي) | تأخير إلزامي للضاغط 180 ثانية ضد التبديل المتكرر |
| **DHT22** | **GPIO 15** | مستشعر الحرارة والرطوبة | فشل آمن يقطع الطاقة عند انقطاع القراءات |
| **Emergency Button** | **GPIO 4** | زر فيزيائي (Pull-up) | قطع فوري لكافة القنوات الأربعة |
| **Status LED** | **GPIO 13** | مؤشر LED | بيان حالة النظام والإنذار |

## ⚠️ تنبيه السلامة الفيزيائية (Physical Safety Warning)

> **تحذير هندسي:** التعامل مع تيار متناوب 220 فولت يشكل خطر صعق كهربائي وحريق. يتطلب الاستخدام الفيزيائي استخدام موديول ريليه معزول بصرياً (Optocoupler Isolation)، وفيوز سريع لكل قناة، وتأريض الحاوية بالكامل ومراجعة مهندس كهربائي معتمد.
